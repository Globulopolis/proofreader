# Proofreader

Proofreader is a Joomla component for typos reporting. Initially created by Sergey M. Litvinov (Joomlatune.ru), later maintained by PavelSyomin and Globulopolis.

This version is for Joomla 5.x. It is also expected to run on Joomla 4.4.x and later. For Joomla 3 and Joomla 4.0–4.3 please consider using [Proofreader Legacy](https://github.com/PavelSyomin/proofreader/tree/legacy).

If you find a bug or have a feature request, please [open an issue](https://github.com/PavelSyomin/proofreader/issues/new/choose).

### Captcha support

Supported services and plugins:

[Google Invisible reCAPTCHA](https://github.com/nikosdion/plg_captcha_google)

[hCaptcha](https://extensions.joomla.org/extension/hcaptcha/)

[Cloudflare Turnstile](https://github.com/SharkyKZ/joomla-turnstile-plugin)

#### Note!

Tag `{proofreader-prompt}` will replace within content with Proofreader's prompt block.
